# Assets

This folder is intended for project visuals.

Suggested structure:

- `original-2017-18/` — original thesis sheets, sketches, plans and photographs from the project period.
- `retrospective-portfolio/` — diagrams, maps, renderings and infographics reconstructed later for portfolio presentation.
- `site-references/` — landscape/site photographs and verified context imagery.
- `case-studies/` — appropriately credited case-study diagrams or links.

## Important

Do not mix retrospective graphics with original thesis drawings without labelling them clearly.
