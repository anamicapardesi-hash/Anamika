# Case Study Notes

## Sula Vineyards — Learning Reference

### Why it was relevant

Sula Vineyards demonstrates how a strong identity can turn a landscape-based production site into a tourism destination.

Relevant lessons:

- create a memorable destination narrative;
- integrate food, landscape and visitor experience;
- use multiple visitor touchpoints;
- build tourism around a strong sense of place;
- create secondary economic activity around the core programme.

### Difference in this project

The proposed Chikhaldara project is **not production-led**.

Its hierarchy is:

**Hospitality first → nature + farms + local culture as supporting experiences**

The visitor comes primarily to stay in the landscape.

Farm visits, coffee/strawberry experiences, local food, walking trails and community interactions enrich that stay.
